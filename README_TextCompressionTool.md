# Text Compression Tool — PS No. 99

A Java console application that compresses text using Huffman coding.

## Requirements
- Java JDK 8 or later

## Compile and run
```bash
javac TextCompressionTool.java
java TextCompressionTool
```

## Features
1. Compress text and display character frequencies indirectly through the Huffman code table, encoded bits, original bit count, and percentage saved.
2. Decode with the Huffman tree generated by the most recent compression.
3. Display the current code table.
4. Decode using a user-entered code table (useful for the assignment's separate decoding test case).
5. Reject empty compression input, non-binary bit strings, invalid code tables, and incomplete encoded strings.

## Huffman rules used
- The two lowest-frequency nodes are repeatedly removed from a min-priority queue and merged.
- The removed node with smaller frequency becomes the left child (bit `0`); the other becomes the right child (bit `1`).
- A single distinct character receives code `0`.
- Original size is calculated as 8 bits per input character, as specified in the assignment.

## Assignment test examples
- Compress `aaaabbc`: codes `a=1, b=01, c=00`; encoded `1111010100`; original 56 bits.
- Compress `aaaa`: code `a=0`; encoded `0000`; original 32 bits.
- Compress empty input: prints `Input is empty. Nothing to compress.`
- Custom decode: enter 3 pairs (`a` -> `1`, `b` -> `01`, `c` -> `00`) and bit string `0100111`; result is `bcaaa`.

Note: the custom decode option accepts a prefix-free code table. It is included because the assignment's fourth test case provides a code table separately from the most recently compressed text.
